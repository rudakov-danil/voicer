# Voicer

Актуальный код работающего сервера на 17 октября 2026 года, включая клиники, кофейни, аптеки, кабинет и мобильное приложение. Основная ветка — `main` в `rudakov-danil/voicer`.

- [Состав снимка и проверки](docs/server-snapshot-2026-10-17.md)
- [Документация проекта](docs/README.md)
- [Опубликованный релиз клиник](docs/medicine-release-2026-10-17.md)

`services/frontend` содержит полные исходники опубликованной сборки; `npm ci && npm run build` проверен по сборке с сервера. `services/mobile` содержит опубликованную оболочку и модули версии `20261017-clinic`.

Для настройки используйте `.env.example`, задав собственные секреты. Рабочие `.env`, ключи, дампы БД, аудио, журналы, зависимости и собранный `dist` не публикуются. Действующие конфигурации доменов сохранены в `deploy/production/nginx/`; сертификаты и закрытые ключи настраиваются отдельно.

Документация `docs/` и `CLAUDE.md` перенесена с сервера. Указания о `Freezy113/voiceiq`, ветках `backup-*`/`master` и неполных исходниках фронтенда относятся к более раннему состоянию; актуальные сведения приведены в описании снимка. GitHub Actions запускается вручную.
