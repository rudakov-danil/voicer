# Приложение сотрудника Voicer

Публичный адрес: https://mobile.voicer-ai.pro/app.html. Исходники мобильной оболочки находятся в этой папке. Разделы: «Моя смена», «Запись», «Монеты». Дизайн соответствует кабинету руководителя.

Руководитель создаёт одноразовую ссылку сотруднику в https://horeca.voicer-ai.pro/motivation. Она действует 24 часа, повторное подключение отзывает старую сессию. Руководители могут войти в приложение с обычными данными кабинета для просмотра. Сотрудники видят только свой профиль.

Аудио сохраняется фрагментами в IndexedDB и отправляется после остановки. Отправка идемпотентна, очередь переживает перезагрузку; прерванный звук требует проверки перед отправкой. Блокировка экрана может прервать запись в мобильном браузере. Не очищайте данные браузера, пока очередь не отправлена. Web Locks ограничивает одновременную запись одной вкладкой.

Монеты начисляются после ручной проверки продажи руководителем. Правила, версии, история, доступ и проверки описаны в [документации мотивации](../../docs/product/motivation.md). Автоматической сверки оплаты с POS и денежного обмена нет.

Оболочка публикуется в `/var/www/voicer-mobile`, модули — в `releases/20261017-clinic`. `app.html` обходит кэш старой HTML-оболочки; service worker обновляет публичные файлы с офлайн-резервом и не перезагружает открытые вкладки. API, токены и аудио не кэшируются service worker.

Для публикации модули JavaScript, CSS и шрифты из этой папки копируются в `releases/20261017-clinic/`, оболочка HTML, manifest, service worker и иконки — в корень web root. Сначала публикуются модули, затем HTML и service worker. Обычные Dockerfile сервисов также содержат необходимый код при последующих полных сборках.

Приложение не показывает цены, суммы заказов и средний чек. Цитаты, советы и описания начислений с денежными значениями скрываются целиком, в том числе при просмотре сохранённых данных. Монеты — отдельные единицы мотивации, заданные руководителем.

Для клиники приложение врача показывает запись и его протоколы. Врач редактирует и подтверждает свои документы; кабинет руководителя ему недоступен.
