# Внутренняя панель — Super Admin

## Что такое admin.voiceiq.ru

`admin.voiceiq.ru` — это внутренняя административная платформа VoiceIQ. Она полностью отдельна от клиентского приложения (`app.voiceiq.ru`) и предназначена только для сотрудников команды VoiceIQ.

Через эту панель команда VoiceIQ:
- Управляет организациями-клиентами
- Регистрирует и привязывает аудиобейджи
- Управляет лицензиями и подписками
- Мониторит техническое состояние платформы

---

## Роли в admin.voiceiq.ru

На MVP — одна роль: **Super Admin**.

### Super Admin

Полный доступ ко всем функциям внутренней панели. Аккаунты Super Admin создаются вручную инженерами VoiceIQ — нет публичной регистрации.

---

## Функциональность

### 1. Управление организациями

**Как появляются организации:** Super Admin создаёт организацию вручную в `admin.voiceiq.ru`. Самостоятельная регистрация клиентов через публичную форму не поддерживается в MVP (запланировано на v2).

**Создание организации:**
1. Super Admin нажимает «Создать организацию»
2. Заполняет форму: название, slug, email владельца (Admin)
3. Система создаёт организацию и отправляет приглашение на указанный email
4. Владелец получает письмо с ссылкой для установки пароля и входа в `app.voiceiq.ru`

**Список организаций:**
- Таблица всех компаний-клиентов
- Колонки: название, slug, дата подключения, статус (активна / заблокирована), количество магазинов, продавцов, бейджей

**Карточка организации:**
- Основная информация (название, контакты)
- Статистика использования: количество разговоров, обработано записей, активные бейджи
- Список магазинов организации
- Текущий статус лицензий (по магазинам)

**Действия:**
- Изменить данные организации
- Заблокировать / разблокировать организацию
- Перейти к управлению бейджами организации
- Управлять лицензиями магазинов организации

---

### 2. Управление бейджами

Центральный реестр всех аудиобейджей платформы.

**Список бейджей:**
- Таблица: серийный номер, организация (или «не назначен»), продавец, статус (online/offline/charging), последняя синхронизация

**Регистрация нового бейджа:**
1. Super Admin вводит серийный номер (или загружает CSV со списком номеров)
2. Привязывает бейдж к организации
3. После этого клиент-администратор видит бейдж в своей панели и может назначить его продавцу

**Альтернативный путь (самостоятельная регистрация клиентом):**
- QR-код на корпусе бейджа содержит серийный номер
- Admin организации сканирует QR в `app.voiceiq.ru` → Устройства → Добавить
- Бейдж автоматически регистрируется и привязывается к организации

**Отвязка бейджа от организации:**
- Если клиент вернул бейдж (конец договора, поломка) — Super Admin может отвязать устройство от организации

---

### 3. Управление лицензиями

**Модель лицензирования:**
- Лицензия выдаётся на **магазин** (не на организацию в целом)
- Лицензия позволяет магазину **подключать аудиобейджи** — без активной лицензии бейдж не может записывать
- Super Admin назначает лицензию вручную на конкретный срок

**Создание / продление лицензии:**
1. Super Admin выбирает организацию → магазин
2. Устанавливает даты начала и окончания действия лицензии
3. Добавляет примечание (например, «оплачено по договору №...»)
4. Система активирует лицензию — магазин может начать использовать бейджи

**Триальный период:**
- Super Admin может выдать триал вручную (тот же механизм — лицензия на ограниченный срок)
- Отдельного автоматического механизма триала в MVP нет

**Просмотр лицензий:**
- Список всех активных и истёкших лицензий по организации
- Колонки: магазин, дата начала, дата окончания, статус (активна / истекла), кто выдал, примечание

**Что происходит при истечении лицензии:**
- Бейджи магазина перестают записывать (или уже записанные данные продолжают обрабатываться)
- Доступ к аналитике сохраняется (исторические данные не удаляются)
- Admin организации видит уведомление об истечении лицензии в `app.voiceiq.ru`

---

### 4. Мониторинг технического состояния

**Состояние очередей:**
- RabbitMQ: размер очередей (`queue.transcribe`, `queue.analyze`, `queue.stitch`), количество задач в DLQ
- Среднее время обработки по каждому шагу пайплайна

**Состояние сервисов:**
- Health checks всех микросервисов
- Uptime за последние 24ч / 7 дней

**Ошибки обработки:**
- Список записей со статусом `error`
- Возможность ручного перезапуска обработки

---

## Аутентификация в admin.voiceiq.ru

Аутентификация Super Admin полностью независима от клиентской (`app.voiceiq.ru`):
- Отдельная таблица `super_admins` в БД
- Отдельный JWT с коротким TTL
- Доступ только из доверенных IP (VPN или корпоративная сеть) — на продакшене

## Разграничение с клиентской панелью

| Аспект | admin.voiceiq.ru | app.voiceiq.ru |
|--------|-----------------|----------------|
| Пользователи | Только команда VoiceIQ | Клиенты (Director, Admin, ROP, Manager) |
| Видимость данных | Все организации | Только своя организация |
| Управление орг-ями | ✅ | ❌ |
| Регистрация бейджей | ✅ (массовая) | ✅ (QR-код, своя орг.) |
| Аналитика продавцов | Только агрегированная статистика | Полная аналитика |
| Управление скриптами | ❌ | ✅ (manager) |
| Техмониторинг | ✅ | ❌ |
