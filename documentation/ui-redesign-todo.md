## Сделано

### Этап 1 — дизайн-система на всех экранах
- Токены концепта в `services/frontend/src/index.css`. Старые имена (`--primary`, `--bg`, `--text`…) работают как псевдонимы новых, поэтому инлайн-стили страниц подхватили палитру.
- Шрифт Onest раздаётся с нашего сервера (`@fontsource-variable/onest`), без Google Fonts.
- Новые `Sidebar` и `Topbar`: светлый сайдбар, разделы «Основное» и «Контроль», период сегментами. Ширина до 1180 px — сайдбар сворачивается в иконки.
- Исходы показываются значками (`OutcomeTag`), аватары нейтральные, таблицы, кнопки, вкладки, фильтры, модальные окна и дровер переведены на новый стиль.
- Удалены фейковые дельты «↑ 12%» на «Обзоре» и «Команде», с экрана входа убраны тестовые логин и пароль.
- **EN/RU:** модуль `src/i18n/` — `t()` / `L()` для нового кода и перевод DOM по словарю `en.ts` для старых экранов. Узлы с `translate="no"` (имена, данные) не переводятся.
- Телефония скрыта флагом `TELEPHONY_ENABLED = false` в `src/lib/terms.ts`. Бэкенд телефонии не тронут.

### Этап 2 — частично
- **Список разговоров** (`pages/ConversationsPage.tsx`):
  - подборки «Требуют внимания», «Нарушения», «"Дорого" без ответа», «Ушли к конкурентам», «Без допродажи» со счётчиками;
  - поиск по фразе из расшифровки с подсветкой найденной реплики;
  - «отпечаток» разговора, шкала балла, допродажа «N из M», флаги нарушений и возражений.
- **Бэкенд списка** (`dashboard-service`):
  - параметры `view`, `q`, `with_counts` в `GET /api/v1/dashboard/conversations`;
  - новый `GET /api/v1/dashboard/conversations/fingerprints?ids=…`;
  - модуль `app/fingerprint.py`: дорожки, метки и сопоставление цитат с репликами;
  - порог «требуют внимания» читается общим хелпером `get_score_threshold`.
- **Страница разговора** `/conversations/:id` (`pages/ConversationPage.tsx`):
  - шапка с вердиктом (исход, балл, нарушения, допродажа);
  - плеер-консоль `components/conversation/Player.tsx`: дорожки «Этапы», «Продавец», «Покупатель», «События», волна из аудио, скорость, пропуск пауз, клавиши;
  - расшифровка с пометками на полях, поиск по ней, режим «Следовать»;
  - справа: итог (резюме ИИ по кнопке), разбор балла по этапам с весами, допродажа, возражения и нарушения, динамика речи;
  - ссылка на момент `?t=`, удаление разговора.
  - Старые ссылки `/conversations?conv=<id>` перенаправляются на страницу разговора.
- **Карточка в API** отдаёт `recorded_at`, сохранённое `summary` и веса этапов (`weight`), этапы отсортированы.
- Общие части карточки вынесены в `components/conversation/shared.tsx`.

## Для проверки локально
- Фронтенд: конфигурация `frontend` в `.claude/launch.json` (порт 3000, проксирует `/api` на локальный стек на :80).
- Изменения бэкенда: `docker compose build dashboard-service && docker compose up -d dashboard-service`.
- В локальной базе заведён тестовый директор `ui-test@voicer.local`. Пароль не хранится в репозитории; удалить пользователя, когда не нужен.
- Во фронтенде у каждого `.tsx` есть скомпилированный `.js` рядом, и Vite берёт `.js`. После правок обязательно запускать `npx tsc` в `services/frontend`.

## Команды для пуша
Запускать из корня проекта:

```bash
git add -A
git commit -m "Редизайн интерфейса (этапы 1–2), EN/RU, телефония скрыта"
git remote add rudakov https://github.com/rudakov-danil/voicer.git
git push -u rudakov HEAD:main
```

`HEAD:main` отправляет текущую локальную ветку в `main` нового репозитория.

В коммит попадает `voiceiq_dump.sql` как демо-данные. Если репозиторий публичный, проверьте, что в дампе нет реальных персональных данных.
