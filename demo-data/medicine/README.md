# Демо клиник «Береке» (medicine.voicer-ai.pro)

Синтетическая многопрофильная сеть в Казахстане: три клиники (Абая и Самал в Алматы,
Есиль в Астане), восемь врачей, 28 дней приёмов. Валюта — KZT, часовой пояс — Asia/Almaty.
Пациенты, врачи, адреса и случаи вымышлены. Медицинские назначения в сценариях служат
для демонстрации контроля качества.

Кабинет показывает протоколы приёмов, сервис и компетентность, нарушения и четыре группы
сигналов фрода: увод пациентов, оплата мимо кассы, лишние услуги и препараты, справки без
оснований. У сигналов есть цитаты из расшифровки. В приложении врача доступны «Запись»
и «Протокол»: врач проверяет черновик, редактирует, подтверждает и копирует его в МИС.

Айгуль проводит полные приёмы; Ерлан спешит; Наталья пропускает вопрос об аллергии;
Марат уводит пациентов и предлагает оплату лично; Динара навязывает обследования;
Сергей бывает груб; Асем улучшает работу по неделям; Бауыржан выдаёт больничные по договорённости.

## Файлы и зависимости

| Файл | Назначение |
|---|---|
| `seed.sql` | Организация, три клиники, восемь врачей и специальности |
| `medicine_demo.py` | Диалоги, протоколы, проверки и сигналы за 28 дней без LLM |
| `ids.txt` | UUID организации `medicine-demo` (одна строка) |

Сначала нужна миграция analytics `0014`. Пресет содержит 19 правил; генератор копирует их
организации. Скрипты продаж и мотивация клиникам не нужны. Основа для правил компетентности —
[клинические протоколы МЗ РК на сайте ННЦРЗ](https://nrchd.kz/clinical-protocols?locale=ru).
В описании собственного правила указывают название, год и нужный фрагмент протокола.

## Установка и обновление

Выполнять на сервере после согласования публикации и резервной копии БД:

```bash
cd ~/voiceiq
ORG="$(cat demo-data/medicine/ids.txt)"
docker compose exec -T analytics-engine alembic upgrade head
docker compose exec -T postgres psql -U voiceiq -d voiceiq -v ON_ERROR_STOP=1 -q < demo-data/medicine/seed.sql
docker cp demo-data/medicine/medicine_demo.py voiceiq-dashboard-service-1:/tmp/medicine_demo.py
docker compose exec -T dashboard-service python /tmp/medicine_demo.py "$ORG" "$(TZ=Asia/Almaty date +%F)"
docker compose exec -T redis sh -c "redis-cli --scan --pattern 'dashboard:*$ORG*' | xargs -r redis-cli del"
```

Генератор пересоздаёт записи, разговоры, расшифровки и протоколы только указанной демо-организации,
включая правки и подтверждения протоколов. Правила и специальности врачей сохраняются.
Для проверки без замены приёмов добавить `--dry`; для фиксированного времени — `--until=12:00`.
Без `--until` сегодняшний день заполняется до текущего времени по Алматы минус пять минут.
При другой дате используется 12:00. Демо зависит от дат; расписание обновления пока не настроено.

## Вход

`DOMAIN_ORGS` в auth-service сопоставляет `medicine.voicer-ai.pro` с `medicine-demo`.
Директор или администратор организации `demo` входит на этот домен своей учётной записью.
Доступ врачу выдаётся в кабинете: «Врачи» → врач → «Приложение врача».
Ссылка одноразовая, с подсказкой `app=clinic`; режим приложения определяется отраслью организации.
